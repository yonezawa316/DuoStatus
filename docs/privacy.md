# 隐私与卸载

DuoStatus Release 只读取本机电量、低电量模式、Wi-Fi 无线电及链路状态，以及全机 VM 内存计数。当前代码没有分析 SDK、远程日志、广告、更新检查或应用主动发起的联网请求。

Wi-Fi 状态不包含 SSID、BSSID、扫描列表或密码，不请求定位权限。程序不读取其他应用的界面或逐进程内存，不需要辅助功能、屏幕录制、管理员或设备控制权限，不改变网络及充电策略。

内存仅保留最新快照，不保存历史。程序未实现主动写入的配置、数据库、运行日志或自有缓存；系统自身管理的 Launch Services 记录、图标缓存和崩溃日志不等于应用持久化数据。

当前版本没有自动启动项、自动更新服务或后台 helper。退出菜单栏应用后，删除安装的 `DuoStatus Release.app` 即可卸载应用；保留源码工程不影响使用或退出。若用户之后自行添加系统登录项，卸载时也应在系统设置中移除该项。

提交问题反馈时，请先去除截图里的网络名称、账号和其他私人信息。诊断只需芯片类型、系统版本、应用版本以及可复现步骤，不需要发送完整系统报告或密码。
