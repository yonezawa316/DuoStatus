# 目录与文件规则

本仓库是独立发布工程，不共享其他版本的可写构建目录、缓存、应用标识或 Git 历史。构建、清理和发布操作只处理本工程，不修改其他版本的应用。

| 路径 | 职责 | Git |
| --- | --- | --- |
| `Sources/` | 原生应用代码 | 保存 |
| `Resources/` | Info.plist、两种图标资源 | 保存；应用只打包浅色图标 |
| `Tests/` | 数据边界、兼容读取、计时器和状态测试 | 保存，不进入应用 |
| `scripts/` | 构建、检查、图标生成与打包 | 保存 |
| `.github/` | CI、问题反馈模板 | 保存 |
| `docs/` | 公共文档与必要预览 | 保存 |
| `docs/local/` | 本机核对记录、原始输出和操作记录 | 忽略 |
| `build/` | 编译产物、模块缓存、临时图标 | 忽略 |
| `dist/` | 应用与默认导出的 ZIP、校验值；CI 使用此位置 | 忽略；安装包通过另行安排的销售渠道交付 |

本地分享包允许通过 `./scripts/package.sh --output-dir ..` 导出到工程上一级目录，与工程文件夹同级；也可显式指定其他已有目录。该例外仅针对 ZIP 与校验文件，构建缓存、应用和源码的归属不变。脚本不会自动清理其他输出目录中的旧包；清理时只处理明确的同名发布产物。

应用内置浅色图标是受版本管理的资源，始终随 `.app` 分发。打包脚本尝试设置的 ZIP Finder 外观图标属于本地文件元数据，是否随发送保留取决于传输方式，不作为应用包完整性的一部分。外观设置工具只保存在 `build/Tools/`，不进入常驻应用。

文本采用 UTF-8、LF；源码类型名与文件名一致。构建脚本相对自身定位根目录，不依赖用户当前目录，不写死用户名或本机路径。共享文档不包含本机路径、账号邮箱、原始性能记录或签名凭据。Swift 短期临时文件使用系统用户临时目录；不清理系统共享缓存。

发布版名称为 `DuoStatus Release.app`，可执行文件为 `DuoStatusRelease`，bundle 标识为 `local.duostatus.release`。脚本不能退出、覆盖或修改其他应用。不得为构建新增登录项、后台 helper、系统授权或全局 Git 配置。

每个可检查阶段保存本地提交；公开前检查暂存内容、历史作者邮箱和打包文件。只保存源文件和必要资源，不把 `.app`、缓存或私钥提交进仓库。准备本地发布文件不代表已经上传到 GitHub。

清理时先退出发布版，再删除本工程内不需要的 `build/`、`dist/`。源码、Git 记录及不可重建的本机记录单独备份。删除发布版不影响其他应用和系统开发工具。
